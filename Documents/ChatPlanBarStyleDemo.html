Demo style — Thanh tiến trình

Mô phỏng ChatPlanBar. Dùng công cụ bên dưới để thử thu gọn/mở rộng, reduce motion và các biến thể style. Đây là preview HTML, không phải build thật.

Biến thể A — Hiện tại (glass + tô nền done + xoay chevron + fade)

Đang dùng trong code hiện tại. Tô nền accent nhẹ cho bước done, chevron xoay mượt, hàng bước fade-in.

Biến thể B — Tối giản (không tô nền, chevron tĩnh)

Bỏ tô nền bước done và hiệu ứng xoay; chỉ còn thanh tiến trình. Nhẹ và ít gây chú ý.

Biến thể C — Đậm (tô nền đậm + thanh dày + bo tròn)

Nhấn mạnh tiến độ: tô nền done đậm hơn, thanh tiến trình dày hơn. Phù hợp khi muốn nổi bật.

Gợi ý: Sếp chọn biến thể → tôi sẽ điều chỉnh ChatPlanBar.swift theo đó (giữ accessibility và reduce motion). Nếu muốn thêm biến thể khác (màu, animation khác), nói thêm.
