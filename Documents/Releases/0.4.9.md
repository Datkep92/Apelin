# Apelin 0.4.9

This release restores Apelin's original background survival behavior across app restarts, screen lock, and app switching.

- Restores synchronous host reconciliation in `ChatRuntime.load()` so saved conversations are followed again after a restart.
- Restores synchronous throwing chat loading in `ChatStore.load()` instead of concurrent decoding that could drop or reorder recovery.
- Restores per-project and manifest watching in `ProjectCatalogMonitor` so project changes are still noticed.
- Maintains the existing chat, visible-project, URL, console, and network-policy behavior.

Install the matching rootless package from `SHA256SUMS`.
