# Apelin 0.4.9

This release makes Apelin start faster and use fewer file-system watchers on devices with many projects and chat histories.

- Chat loading now decodes conversations concurrently, so startup recovery reaches cached transcripts sooner.
- A single malformed chat no longer prevents the rest of the chat list from loading.
- Project catalog monitoring now watches only the app and projects roots, reducing descriptor/watch overhead.
- Maintains the existing chat, visible-project, URL, console, and network-policy behavior.

Install the matching rootless package from `SHA256SUMS`.
