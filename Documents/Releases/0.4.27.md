# Release 0.4.27

Relaxed packaging and language restrictions so compatible external tools can be used when explicitly requested.

- The agent no longer presents toolchain, Theos, dpkg, SDK and apt installation as permanently forbidden; such changes require your explicit request and suitable device support.
- Installation remains handled by Apelin's installer whenever possible, with risks documented.
- No user-visible layout, gesture, runtime or accessibility changes.
- Version and release notes updated for the 0.4.27 build.

Use the rootless arm64 build on iOS 16+, or the roothide build where applicable. Verify package SHA256 from SHA256SUMS before installing.
