# Release 0.4.16

Corrects plan interaction in chat: the action buttons now render in the expanded process card, and the process board is made compact and modern, with newest steps shown first.

- Fix ChatPlanBar so Pause/Resume, End Plan, and Clear are added to the expanded action row.
- Compact and modernize the expanded board: tighter header, step spacing, button size, corner radius and shadow.
- Show the expanded process table newest-first so the latest work appears without scrolling.
- Retain compatibility with the existing plan state and step-detail callback path.

Use the rootless arm64 build on iOS 16+, or the roothide build where applicable. Verify package SHA256 from SHA256SUMS before installing.
