# Apelin 0.4.14

Hardens Phase 1 of the local `.apelinbak` configuration bundle: archive size and file count limits, duplicate path and schema validation, payload/checksum consistency, and symlink-aware extraction containment before writes. Adds regression tests for these defenses.

- Config bundle core now has compile/runtime tests to be verified in CI.
- App-side export/import, backup/rollback, secret token mapping, and runtime reload remain pending for a later release.
