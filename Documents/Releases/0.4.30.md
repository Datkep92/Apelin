# Release 0.4.30

Group model picker by Base URL.

- Configurations in the chat model picker are now grouped by their canonical Base URL: configurations pointing at the same endpoint appear as one group, in the order they are first seen.
- A group's title is the shortened endpoint address; a group with a single configuration keeps its own name.
- Choosing a key, retrying and sending a model behave as before.
- The grouping helper is UIKit-free and covered by six transcript test scenarios.

Use the rootless arm64 build on iOS 16+, or the roothide build where applicable. Verify package SHA256 from SHA256SUMS before installing.
