Apelin 0.1.6 makes the reasoning level you pick reach API-key models, and keeps the conversation still while it scrolls.

- With an OpenAI API key, Maximum reasoning was sent as High. It is now sent as Maximum.
- With an Anthropic API key, Claude models gave the same thinking at High and Maximum. They now use adaptive thinking, so the two differ as they do when signed in with a Claude subscription.
- Scrolling a conversation could make the colour behind a message or an image album slide or stretch for a moment. It now stays put; only a message that actually changes fades.
- After turning a model off in Model Providers, the next message could still go to it. The composer now switches to an enabled model straight away.

Requires iOS or iPadOS 16.0 or later, an A12 chip or later, and Irisin 4.7.3 or later. Choose the `iphoneos-arm64e` packages for RootHide or the `iphoneos-arm64` packages for rootless, and check each download against `SHA256SUMS`.
