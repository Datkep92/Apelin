Apelin 0.3.6 fixes a timing issue in the pushed project picker so selecting a project reliably opens the page that asked for it.

- Settings ▸ Services could still fail to open after selecting a project because the picker's selection callback could run while the pop animation was in progress; the callback now waits for the pop to finish before pushing the Services page.
- The same timing fix applies to All Projects and the Git flow that open a project picker as a pushed page.
- No other behaviour changes.

Requires iOS or iPadOS 16.0 or later, an A12 chip or later, Irisin 4.7.3 or later and icli 0.10.0 or later. Choose the `iphoneos-arm64e` packages for RootHide or the `iphoneos-arm64` packages for rootless, and check each download against `SHA256SUMS`.
