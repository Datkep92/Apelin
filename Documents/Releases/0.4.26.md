# Release 0.4.26

Build and agent process tools now stop unbounded runs and bound their captured output.

- A build tool no longer runs forever without a limit: the default 1800-second timeout sends `SIGKILL` to its process group, and cancellation still aborts the tools at once.
- Polling reads keep checking cancellation and timeout instead of blocking on input, and output is capped at 64 MiB.
- The agent's cancellation registration also cancels its wrapping task, so a timed or cancelled run unwinds cleanly.
- No layout, gesture, runtime, or accessibility behavior changes.

Use the rootless arm64 build on iOS 16+, or the roothide build where applicable. Verify package SHA256 from SHA256SUMS before installing.
