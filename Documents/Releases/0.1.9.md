Apelin 0.1.9 lets the agent ask before it runs a command as root, and answers in the language you write.

- A long chat could open in its middle: a 14-turn conversation came up at its 7th turn instead of the newest message. It now opens at the latest message.
- A reply that paused to write a tool call looked stopped, because no event arrived while the model worked. A Thinking… line now stands in until output resumes, with the number of tokens received so far and a downward arrow after it.
- The thinking summary previewed its own text and shimmered while streaming, and its details were drawn as Markdown, so command lines and file contents read as one escaped line. The summary now shows only its title, its time and tool count; the details are plain text with each argument on its own line.
- The newest tool call disappeared from under the running summary. It is back, with the file it touched and its added and removed lines.
- VoiceOver skipped the assistant's replies. It now reads them, including replies written before this build.
- The agent answered in Chinese when you wrote in English. It now replies in the language you write; when your message is only code, a log or one word, it follows the device's language.
- The agent could only run commands as the app's own user, so anything needing root failed. It can now run one as root once you approve it with Face ID, Touch ID or your passcode; a device with no passcode passes, every other failure approves nothing. Full mode stops it asking, and leaving Full asks nothing.
- The approval card repeated the gate's sentence in grey, showed a root command as `["id","-u"]`, and hid the reason the agent gave. The card now shows that reason, the command as you would type it, and a single red Runs as root line.
- The agent could only work inside the project it was opened for. It can now create a project from any chat, list the device's projects, rename its own project, and list, save or remove your skills.
- The agent had no way to tell you something while you were away. Its notification tool posts a title and a body for what is worth knowing — a long build, install or setup that ended — and never for routine progress.
- Long conversations stuttered while a reply streamed, because every event batch rebuilt the whole transcript. A 10,000-event chat now updates in about a millisecond instead of 155.
- Every message resent a system prompt that changed with the date, the approval mode, a new memory or a new skill, so the provider re-billed the whole conversation. The system prompt is now taken once when a session opens, and only what changed rides on the next message, which keeps the cached prefix intact.
- Asked how to write a tweak, the agent explained Logos and Theos, which Apelin does not use. Its tweaks are plain Objective-C, and it now says so and reads the matching skill first.

Requires iOS or iPadOS 16.0 or later, an A12 chip or later, and Irisin 4.7.3 or later. Choose the `iphoneos-arm64e` packages for RootHide or the `iphoneos-arm64` packages for rootless, and check each download against `SHA256SUMS`.
