The first release of Apelin: write, build, install and debug tweaks, apps, command-line tools and preference bundles on a jailbroken iPhone or iPad, with no Mac.

- Set up a compiler on the device. Apelin downloads Apple's Command Line Tools and adapts them to iOS: C, C++ and Objective-C, and Swift on the releases that support it.
- Download an iPhoneOS SDK, or import one from a file. Each one is checked before a project can use it.
- Start a project from a template (tweak, app, command-line tool or preference bundle) or from an empty workspace that uses your own build system.
- Build, sign, package and install in one step, then respring and see whether your tweak loaded.
- Read the live log and your crash reports, symbolicated against your own builds.
- Chat with an agent that edits, builds, installs and debugs the project with you. Sign in with GitHub Copilot, Claude, ChatGPT, OpenRouter and many other providers, or use your own API key. In Strict mode, anything beyond a project edit or a read-only check waits for your approval.
- A chat can open other chats in the same project, send them work and read their replies.
- Use a terminal and git in the project. Each host's token stays in the keychain.
- Move a toolchain, an SDK or a project to your other device as one file.
- Use the app in English or Simplified Chinese.

Requires iOS or iPadOS 16.0 or later, an A12 chip or later, and Irisin 4.7.3 or later. Choose the `iphoneos-arm64e` packages for RootHide or the `iphoneos-arm64` packages for rootless, and check each download against `SHA256SUMS`.
