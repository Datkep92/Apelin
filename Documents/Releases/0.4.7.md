# Apelin 0.4.7

This release finishes the session Plan bar's resume behavior: resuming an active plan now starts a real follow-up run instead of only changing plan state.

- Fixed plan resume so it kicks off a real run when the plan still has work left.
- Guarded auto-resume against an already-running task, completed plans and run failures.
- Resume prompt failures are logged as an error instead of disappearing silently.

Install the matching rootless package from `SHA256SUMS`.
