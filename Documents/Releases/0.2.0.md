Apelin 0.2.0 signs in to GitHub with a code, and publishes a project's release build to a package repository of your own.

- Using GitHub meant typing a personal access token, and a token that ran out had to be replaced by hand. Settings ▸ Git now signs in with a code, the way `gh auth login` does: the code is shown with a copy button, Safari opens GitHub's page, and the app finishes by itself once you approve. Sign Out forgets the account.
- The welcome flow now offers the GitHub sign-in and the package repository too; either can be left for later.
- A finished release build could only be exported as a file and sent on by hand. Its `…` menu now has Publish to Package Repository: the package is checked against its digest, added to your repository, committed and pushed, and the repository's workflow indexes it, so a source that has the address sees it within a few minutes.
- Setting up a package repository meant writing the `debs/` folder, a depiction, an index script and a workflow yourself. Settings ▸ Git ▸ Publishing creates one from Apelin's template, or links a repository you already have and adds the parts it lacks, turning on GitHub Pages; its address is one tap to copy into your package manager.
- A new project had no repository, so its changes had no history and could not be pushed. Every project now starts as a repository on `main` with no commit; the agent can add one to an older project and commit all of a project's changes in one step.
- A skill you added under a name Apelin's own skills used was skipped, with a message asking you to rename it. The built-ins are now named `apelin-…`, a skill keeps whatever name you give it, and instructions from earlier still find them under the old names.
- The token count beside a running summary jumped to each new total. It now climbs to the run's latest count and settles as the reply begins.

Requires iOS or iPadOS 16.0 or later, an A12 chip or later, and Irisin 4.7.3 or later. Choose the `iphoneos-arm64e` packages for RootHide or the `iphoneos-arm64` packages for rootless, and check each download against `SHA256SUMS`.
