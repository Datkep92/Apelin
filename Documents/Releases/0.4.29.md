# Release 0.4.29

Trace process list reads faster in compact rows.

- Rows keep their localized title, while the line below now prefers the agent's own (often localized) reason and then the result/content before CLI-style details such as argv, command, script, path, or pattern.
- When a reason repeats the title, it is not duplicated.
- Existing animation and token display behavior is unchanged.

Use the rootless arm64 build on iOS 16+, or the roothide build where applicable. Verify package SHA256 from SHA256SUMS before installing.
