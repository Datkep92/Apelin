Apelin 0.1.7 keeps the speed and reasoning level you pick, and distributes a workspace built by its own script.

- Speed could fall back from Ultrafast to Standard on its own, and the reasoning level could reset after you tried another model. Both now stay as you set them: a model that does not offer your choice uses the closest one it has, and the next model that offers it gets it back.
- Distribute… was greyed out for an imported repository, saying it needed a build description, even when its build script made a package. It now builds the target you choose with the workspace's own script and exports that package, and afterwards points out a placeholder identifier, a version already packaged for that target, or a package that differs from the other target's.
- The distribution page let you start a build the project check already knew would fail. It now lists what is wrong and keeps Build off until it is fixed, and the agent's distribution check no longer calls such a project ready.

Requires iOS or iPadOS 16.0 or later, an A12 chip or later, and Irisin 4.7.3 or later. Choose the `iphoneos-arm64e` packages for RootHide or the `iphoneos-arm64` packages for rootless, and check each download against `SHA256SUMS`.
