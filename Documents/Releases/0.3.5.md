Apelin 0.3.5 fixes opening Services and other pages reached through a project picker.

- Settings ▸ Services could not be opened from Settings because the project picker shown there never reported its selection when it was pushed onto the navigation stack; selecting a project now opens that project's Services page.
- The same fix applies to All Projects and the Git flow that open a project picker as a pushed page, so a chosen project is acted on instead of being ignored.
- No other behaviour changes.

Requires iOS or iPadOS 16.0 or later, an A12 chip or later, Irisin 4.7.3 or later and icli 0.10.0 or later. Choose the `iphoneos-arm64e` packages for RootHide or the `iphoneos-arm64` packages for rootless, and check each download against `SHA256SUMS`.
