# Release 0.4.23

Fixes a startup issue in the background service so that the cold-start improvements shipped in 0.4.22 work as intended: App now waits for the service during cold start, and the service exits after inactivity without crashing on startup.

- Background service now starts correctly with the updated inactivity window and startup logging.
- App's cold-start wait and service task-log pruning changes from 0.4.22 remain in effect.
- No user-facing behavior change beyond preventing silent background service failures during launch.

Use the rootless arm64 build on iOS 16+, or the roothide build where applicable. Verify package SHA256 from SHA256SUMS before installing.
