# Release 0.4.15

Brings configuration portability into the app: Settings ▸ Agent ▸ Configuration now exports and imports a `.apelinbak` archive of memories, skills, commands, allowlisted Git/distribution/provider settings, and project display names.

- Export collects the portable scope, builds a `.apelinbak`, presents the share sheet, and removes its temporary file.
- Import verifies the bundle, backs up touched files, extracts safely with rollback, updates only existing project display names, and posts a reload notification.
- Import guards against symlinks, traversal, absolute paths, non-canonical paths, and oversized files.
- Backup and rollback keep a failed or invalid import from leaving a partial configuration behind.
- Core checks from 0.4.14 remain in place; compilation and runtime behavior still depend on CI and device verification.

Use the rootless arm64 build on iOS 16+, or the roothide build where applicable. Verify package SHA256 from SHA256SUMS before installing.
