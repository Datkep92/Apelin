# Release 0.4.19

The "Quá trình" (Trace) sheet of a turn now reads the way the process board above the composer does: the newest step stands at the top, each row's second line says what the call did, and the sheet keeps no step text between pages.

- Opening the sheet while the agent was still running showed the turn's first steps and hid what it is doing now. The newest step is at the top, the same order as the process board; the rows carry no numbers, so nothing is renumbered, and a row still opens its own step.
- A row's second line was the agent's own reason, written in English, so a row of work usually read as prose about why rather than about what. It now names the file or folder, the command, the script or the pattern the call used, keeps the reason when the call names nothing of its own, and still ends with the result.
- Opening several steps kept every step's text and height in memory for the rest of the session. The page that is open now holds only the text it shows, so a redraw does not decode the file again and closing the page releases the memory.

Use the rootless arm64 build on iOS 16+, or the roothide build where applicable. Verify package SHA256 from SHA256SUMS before installing.
