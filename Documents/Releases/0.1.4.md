Apelin 0.1.4 shows you the agent's skills in Settings and builds an imported repository with its own script.

- You could not see which skills the agent uses, read one, or tell why a skill you added was ignored; Settings ▸ Agent ▸ Skills now lists Apelin's built-in skills and yours, opens each one's instructions, and explains any skill that is not used.
- Add a skill from Files — a folder with a SKILL.md, or a single Markdown file — with the plus button, and remove one of yours with a swipe. Skills apply to every chat.
- A repository you imported could be built but not installed; a workspace can now name its own build script, and the package it writes installs, removes and is checked like any other build. In Strict mode, Apelin asks before every such build, and before installing a package whose contents changed.
- The agent knows how to set up a workspace's build script, and points a Theos tweak at one instead of rewriting it.

Requires iOS or iPadOS 16.0 or later, an A12 chip or later, and Irisin 4.7.3 or later. Choose the `iphoneos-arm64e` packages for RootHide or the `iphoneos-arm64` packages for rootless, and check each download against `SHA256SUMS`.
