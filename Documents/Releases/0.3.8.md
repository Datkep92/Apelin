Apelin 0.3.8 keeps a chat going when a model refuses or runs out, sends pictures the way each endpoint wants them, and gives the agent new hands: running a program, undoing a file edit, and five more ways to touch the screen.

- A chat that ended because a model's allowance was spent had no way forward: Apelin now sends the message again on the next model, with the files it carried, and the Retry button in the model bar works again — a retry no longer answers or sends twice.
- A key refused or rate-limited in the middle of a chat left it stuck: the chat is now marked and tries the next model or key on its own, including when the key itself was refused.
- One provider could keep only one key: a provider now keeps as many configurations as you like, each with its own key and model list, and the model picker shows one row per provider with no repeated model names.
- Keys for the same Base URL each kept a separate model list: they are now grouped by address, share one model list, and deleting a key keeps the list for the others. Saving a key for an OpenAI-compatible or Anthropic endpoint no longer re-checks every model first.
- A picture went out exactly as it was, however large: it is now prepared to what the endpoint accepts (long side 1568 px for Anthropic, 2048 px for OpenAI-compatible), the same prepared copy is reused byte for byte on a retry, and it is prepared again after switching model. The transcript says how much the endpoint served from cache ("· 12% cached").
- Logging in to Cloudflare failed even with a valid token, and Firebase and Google Script services had no way in: Cloudflare now logs in by listing the account, and every service accepts a pasted access token.
- The agent could write files but could not run anything: `code_run` runs a program the model wrote — sh, bash, zsh, python3, perl or node — as the ordinary user, with its arguments checked and a timeout, and only once you approve it.
- An agent edit overwrote a file with no way back: each write leaves a copy, `file_backups` lists them and `file_revert` puts one back, so an unwanted edit can be undone in either direction.
- The agent could only tap, type and swipe the screen: it can now also double-tap, long-press, drag a path, press a key and open a URL.
- The launch journal now records the screen actions Apelin performed and the tools that failed, so a run that went wrong can be read back.
- The project list button sits in the sidebar footer and opens the list as a pushed screen; both drawers open by swiping, and the Services picker pushes in place.
- Opening an old chat now scrolls to its newest message, and the HTML playground no longer opens by itself at startup from a leftover file.

Requires iOS or iPadOS 16.0 or later, an A12 chip or later, Irisin 4.7.3 or later and icli 0.10.0 or later. Choose the `iphoneos-arm64e` packages for RootHide or the `iphoneos-arm64` packages for rootless, and check each download against `SHA256SUMS`.
