# 0.4.42

Starts up faster and uses less memory: chat history and events are loaded on demand instead of all at once, and the log calls that failed to compile are fixed.

## What changed

- Chat events are stored in a separate file per conversation and loaded only when the conversation is opened or is actively working, instead of loading every conversation's full history at launch.
- Startup reconciliation runs in the background and loads events only for working or live sessions.
- Removed unused event data from the in-memory record after persisting, reducing memory pressure.
- Fixed `os_log` calls in ChatRuntime that used an invalid `subsystem:` argument label, which prevented compilation.
