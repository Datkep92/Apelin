Apelin 0.2.1 lets the app reach the network where the system had kept it offline, and opens a message from a link for you to send.

- Sign In with GitHub could fail with "The Internet connection appears to be offline" while every model provider signed in fine. Apelin now allows itself Wi-Fi and cellular data when it starts.
- In Dark Mode before iOS 26, the button on the GitHub and model provider sign-in pages (Sign In, Open GitHub, Try Again) was white text on a white fill. It is readable now.
- Another app or a web page can open `apelin://chat?prompt=…`: Apelin starts a new General Chat with that text in the message field and the keyboard up, and sends nothing until you tap Send.
- Apelin now installs icli with it, and the agent uses it for device tasks Apelin has no tool of its own for. If icli is missing, the agent asks you to install it from apt.owngoal.dev.

Requires iOS or iPadOS 16.0 or later, an A12 chip or later, Irisin 4.7.3 or later and icli 0.9.2 or later. Choose the `iphoneos-arm64e` packages for RootHide or the `iphoneos-arm64` packages for rootless, and check each download against `SHA256SUMS`.
