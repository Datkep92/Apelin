# Release 0.4.13

Task progress views are easier to follow and control: the full task log now shows newest activity first while retaining stable line numbers, failed tasks show an obvious Done button, and Stop is directly visible while a task is running.

- Full task log now places newest entries at the top and keeps chronological line numbers.
- Finished tasks expose Done consistently, including failures.
- Running tasks expose Stop directly in the action bar while the request is accepted.
- No service, storage, model, accessibility, or gesture changes; presentation/runtime behavior preserved.

Use the rootless arm64 build on iOS 16+, or the roothide build where applicable. Verify package SHA256 from SHA256SUMS before installing.
