Apelin 0.4.6 simplifies the chat composer by removing the Web and HTML buttons from the attachment panel, while keeping automatic web and HTML previews working.

- The composer attachment panel now shows only Camera, Photo and File, reducing crowding and making the remaining buttons easier to tap.
- Removing the Web and HTML buttons does not remove the underlying web capture/import flow or the HTML playground; HTML written by the agent still opens the preview automatically.
- The attachment panel count and accessibility labels were checked after the layout change.

Requires iOS or iPadOS 16.0 or later, an A12 chip or later, Irisin 4.7.3 or later and icli 0.10.0 or later. Choose the `iphoneos-arm64e` packages for RootHide or the `iphoneos-arm64` packages for rootless, and check each download against `SHA256SUMS`.
