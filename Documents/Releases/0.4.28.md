# Release 0.4.28

Model and API-key switching now activates for real quota messages.

- When a provider says the allowance, free usage, credits, balance, or budget is
  exhausted or insufficient, Apelin treats it as a spent allowance and tries the
  next configured key or model instead of staying on the broken one.
- Payment-required, rate-limit, and token-harbor quota messages are now detected
  on both app and daemon paths, and numeric statuses must stand alone.
- This automatic switch is not limited to bare HTTP 429 responses.
- No layout, gesture, or accessibility behavior changes.

Use the rootless arm64 build on iOS 16+, or the roothide build where applicable. Verify package SHA256 from SHA256SUMS before installing.
