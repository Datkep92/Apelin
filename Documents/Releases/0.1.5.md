Apelin 0.1.5 stops an arm64e build that would crash as soon as it runs.

- A tweak or tool linked with `-undefined dynamic_lookup` (or `suppress`) on Command Line Tools 15.0 built and installed, then crashed on arm64e the first time it used a string constant or called a system function. That build now stops at the link step and says why: name a symbol left to load time with `-Wl,-U,_symbol` instead, or build with another toolchain.
- The agent no longer adds that flag when it links a tweak or writes a build script.

Requires iOS or iPadOS 16.0 or later, an A12 chip or later, and Irisin 4.7.3 or later. Choose the `iphoneos-arm64e` packages for RootHide or the `iphoneos-arm64` packages for rootless, and check each download against `SHA256SUMS`.
