# Apelin 0.4.62

Fixes the empty-app regression caused by adopting `com.apple.private.security.container-required`: Apelin now ignores the data container and always reads/writes through mobile's home at `/var/mobile/Documents/wiki.qaq.apelin` (roothide: `<jbroot>/var/mobile/...`), while keeping `container-required` so WebKit works. All app data (skills, projects, chat sessions, commands, playground, journal) lives under `DataFolder.app`.

Also fixes the session-host harness test that checked the removal's log event kind.

Choose the rootless package `wiki.qaq.apelin_0.4.62_iphoneos-arm64.deb` for this device; SHA-256 in `SHA256SUMS`.
