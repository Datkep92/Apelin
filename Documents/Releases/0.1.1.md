Apelin 0.1.1 smooths the chat, adds home screen widgets and notifications, and lets the agent set up the device and work across projects.

- On iOS 17, the first line of a list item no longer starts further right than the lines under it.
- Sending a message in a long conversation no longer makes the list jump to the top or flicker.
- The chat now follows a reply to the end while it streams at reading speed. A faster reply stops after a page, and the arrow takes you to the newest text.
- Tables and code blocks fade in as they stream, like the rest of the reply.
- Home screen widgets show the chats that are working, waiting for your approval or failed. While a chat works, a Live Activity shows on the Lock Screen. Tap either to open that chat.
- When Apelin is in the background, it notifies you when a chat finishes or needs your approval.
- `apelin://conversation/…` and `apelin://project/…` links open a chat or a project. The agent writes these links when it points you to another chat.
- The agent can list, set up and test toolchains, import SDKs, and switch a project to a toolchain and SDK that fit. In Strict mode, each setup and import asks first.
- From General Chat or any project, the agent can start and message chats in another project. In Strict mode, it asks first.
- The agent knows the device's iOS version, toolchains and SDKs, and starts each chat with the project's details and files. Its commands and your terminal get the project's toolchain and SDK without extra flags.
- The sidebar's plus button now offers New Chat and New Project.
- Before iOS 26, buttons and highlights are black or white instead of blue.
- Drop files and images on the message field to attach them.
- Rename a chat from its … menu. General Chat's … menu opens its folder in iGhostVT or Fila, and Model Providers is no longer in the chat menu.
- Distribute… is unavailable for a project without a build description.
- Settings has a Logs page under About. Its … menu opens the onboarding again or reports a problem on GitHub.

Requires iOS or iPadOS 16.0 or later, an A12 chip or later, and Irisin 4.7.3 or later. Choose the `iphoneos-arm64e` packages for RootHide or the `iphoneos-arm64` packages for rootless, and check each download against `SHA256SUMS`.
