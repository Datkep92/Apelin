Apelin 0.4.0 gives every conversation a plan bar: the steps the agent means to take, where each one stands, and the buttons to pause, resume or end the plan.

- A long task now shows its plan above the message box: closed it is one line — how many steps are done and what the agent is doing now — and opened it is the steps themselves, each with the tool result that backs it.
- The plan outlives everything a chat goes through: a summary of the conversation, a switch to another model, Apelin restarted or the chat opened again all reach the same steps, and a step already done is not done twice.
- The agent writes the plan and moves it on, one step at a time; the user pauses, resumes, ends or clears it from the bar, and a step that failed is named rather than passing as finished.
- Importing a file from Recents or iCloud Drive in a chat works again: the file chosen is attached instead of the picker closing on nothing.
- A small helper script lets the agent tap and swipe the screen, and switch apps, on a device with ZXTouch installed.
- Host test and compile fixes keep the build's verification green.

Requires iOS or iPadOS 16.0 or later, an A12 chip or later, Irisin 4.7.3 or later and icli 0.10.0 or later. Choose the `iphoneos-arm64e` packages for RootHide or the `iphoneos-arm64` packages for rootless, and check each download against `SHA256SUMS`.
