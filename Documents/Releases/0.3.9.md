Apelin 0.3.9 lets the agent drive a browser as a page, read a screen without paying for the whole tree, and switch models or keys mid-chat, with code_run able to run as root like shell_run.

- The agent can now drive a browser as a page: one tool with one action, instead of juggling separate calls.
- A screen read is narrowed before the model pays for it, and the filter is applied in the session worker on the tree already received, so less is sent and less is charged.
- Reading a file a tool is asked for and showing a screen it captured now work even when the result is large.
- code_run can run as root, the way shell_run does, when the task needs it.
- A key is named as the one that sends a model, and the reader can switch it in the chat; a failed message is sent again on another key or model, chosen from what the failure says.
- A key's models are grouped by its whole Base URL, not by the endpoint host, so one address keeps one model list.
- Host test harness and compile fixes keep the build's verification green.

Requires iOS or iPadOS 16.0 or later, an A12 chip or later, Irisin 4.7.3 or later and icli 0.10.0 or later. Choose the `iphoneos-arm64e` packages for RootHide or the `iphoneos-arm64` packages for rootless, and check each download against `SHA256SUMS`.
