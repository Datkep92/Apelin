# Release 0.4.25

Refines the plan progress bar's compact badge: it now floats as an overlay without affecting chat content, with smoother color and progress animation, a restyled hide button, and a subtle blur and shadow for a more polished look.

- Compact badge overlays the composer instead of occupying content height; chat content stays scrollable.
- Color and progress (stroke) animate smoothly; spin animation remains for active plans.
- Hide button restyled with rounded background.
- Compact badge now has a subtle blur and shadow for a nicer, more professional appearance.
- Hidden state remains in-memory only and resets when the plan clears.

Use the rootless arm64 build on iOS 16+, or the roothide build where applicable. Verify package SHA256 from SHA256SUMS before installing.
